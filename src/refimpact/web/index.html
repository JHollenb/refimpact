How to read this comparison

Each game appears once, in the home-team direction. We compare net measured EPA with the final score margin. Games with incomplete play-by-play or no value for the selected metric are excluded. A tie or zero net benefit is excluded only from the “benefited team won” count.

The interval resamples games and is exploratory; the same teams recur across games. This analysis does not control for team strength, penalty opportunities, coaching or game state. Win probability itself already uses the score and clock, so its relationship with winning is partly built into the model. We use EPA for this comparison instead of adding win-probability swings.
